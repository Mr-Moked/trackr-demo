# Backlog Trackr

Fonctionnalités demandées par les utilisateurs. Chaque fonctionnalité est découpée en issues avant d'être développée (une issue = une personne = une Pull Request).

| ID | Fonctionnalité | Précision |
|---|---|---|
| F1 | Filtrer les colis par statut | Exemple traité dans le livret de la séance 1 |
| F2 | Trier la liste par date de livraison estimée | Ordre croissant ou décroissant |
| F3 | Page de détail d'un colis | Historique des étapes du colis |
| F4 | Marquer un colis comme favori | Les favoris restent en haut de la liste |
| F5 | Ajouter un colis | Formulaire : numéro de suivi et nom |
| F6 | Liste vide | Message et invitation à ajouter un colis |
| F7 | Thème sombre | Bascule clair / sombre |
| F8 | Dernière mise à jour | Date et heure affichées sur chaque colis |

Le détail (ce que disent les utilisateurs, questions à trancher) est dans le document TP1_02 Ressources.
